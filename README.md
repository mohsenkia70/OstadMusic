# 🎻 Ostad Music

A modern, high-performance online music education platform built with **Next.js 16**, **React 19**, **TypeScript**, and **Tailwind CSS**.

Ostad Music connects students with professional musicians through an elegant, responsive, and scalable platform designed specifically for music education.

---

## ✨ Features

* 🎻 Beautiful modern UI/UX
* 🌙 Fully responsive design
* ⚡ Built with Next.js 16 App Router
* 🎨 Tailwind CSS 4
* ✨ Smooth animations using Framer Motion & GSAP
* 🎼 Music teacher profiles
* 👨‍🎓 Student dashboard (planned)
* 👨‍🏫 Teacher dashboard (planned)
* 📅 Lesson booking system (planned)
* 💬 Real-time communication architecture
* 📹 WebRTC signaling server
* 🔐 Authentication-ready architecture
* 📊 Interactive charts using Recharts
* 🎹 Zustand state management
* 🧩 Modular and scalable project structure
* 🌍 RTL & Persian language support
* 🚀 Production-ready architecture

# 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/mohsenkia70/OstadMusic.git
```

Enter the project

```bash
cd OstadMusic
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Open

```text
http://localhost:3000
```

---

# 📜 Available Scripts

Start development server

```bash
npm run dev
```

Build production

```bash
npm run build
```

Start production server

```bash
npm run start
```

Run ESLint

```bash
npm run lint
```

Run WebRTC signaling server

```bash
npm run signaling
```

Test signaling server

```bash
npm run test:signaling
```

Test authentication client

```bash
npm run test:auth
```

# 🏗 Architecture

The project follows a modular architecture that allows future expansion without major refactoring.

```
Frontend
    │
    ▼
Next.js App Router
    │
    ├── UI Components
    ├── State Management
    ├── Forms
    ├── Authentication
    ├── Teacher Module
    ├── Student Module
    └── Booking Module
            │
            ▼
     Signaling Server
            │
            ▼
        WebRTC Services
```
